## First react app

## installation

`npm init`

`npm i react`
 
`npm i react-dom`

`npm i -d parcel`

`npm start`

- To initialize the node module packge, we do npm init
- later install couple of packages react and react-dom
- After that install parcel -- bundler which will bring babel to convert jsx into html
- Update package.json file -- npx is to execute the command
    "script" :  {
        "start" : "npx parcel index.html"
    }
- run the project
- update the gitignore file
