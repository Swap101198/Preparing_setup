# First react App

## Installation

`npm init` 

`npm i react` 

`npm i react-dom`

`npm i -d parcel`

- First install the node package manager.
- Later install react and react-dom lib.
- After that install parcel it does work of bundling as well as it install babel
- *create .gitingnore file*
     fileName/ complete directory

    {"start":"npx parcel index.html"}
